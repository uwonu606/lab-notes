git 물건과 이름표

amend, rebase, squash 가 전부 같은 한 가지 일이라는 것을 그림 여섯 장으로.

커밋은 물건이다. 한번 만들면 못 고친다.

브랜치는 이름표다. 커밋 하나만 가리킨다.

그래서 amend 는: 새 물건 하나, 이름표 한 칸

커밋 수는 그대로 3. 옛 c3 는 지워지지 않았다.

그래서 rebase 는: 새 물건 여럿, 이름표 한 칸

7개를 다시 재생해 4개를 만들었다. 옛 7개는 남는다. reflog 가 이름표의 이동을 기억한다.

main..feature 는 두 이름표의 차이

feature 에서 거슬러 갈 수 있는데 main 에서는 못 가는 커밋. 점 두 개의 왼쪽이 빼는 쪽.

브랜치를 main 에 얹는 세 가지

Matt 의 저장소는 첫 번째라 main 이 459개. pstack 은 두 번째라 main 이 86개.
